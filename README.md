# 🛒 ShopSmart – Python Shopping Application

Welcome to **ShopSmart**, a simple yet powerful shopping application built with Python. Designed to make shopping easy and enjoyable, this project demonstrates the fundamentals of Python through a real-world online shopping experience.

## ✨ Features

* 🛍️ Browse a collection of products
* ➕ Add items to your shopping cart
* ➖ Remove unwanted items
* 💰 View your total bill instantly
* 🧾 Experience a simple checkout process

## 🚀 Why This Project?

ShopSmart was created to practice Python programming concepts such as:

* Variables and data types
* Functions
* Loops and conditional statements
* Lists and dictionaries
* User input handling

## 🛠️ Built With

* **Python 3**
* Standard Python libraries

## ▶️ Getting Started

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the application:

   ```bash
   python main.py
   ```
4. Start shopping! 🎉
